# BILIM QUEST — GitHub Pages | Қайнау температурасы

Бұл сайт **қазақ тілінде** әдепкіде ашылады. Орысша нұсқа жоғарғы оң жақтағы **РУС** түймесі арқылы қосылады.

## Сайтта дайын тұрған сабақ

**Тақырыбы:** «Қайнау температурасының атмосфералық қысымға байланыстылығын анықтау». Физика пәнінде **10 «Дұрыс / Бұрыс» сұрағы** бар. Дұрыс жауаптар берілген. Әр сұрақ 1 ұпай, нәтиже 10 балдық жүйеге келтіріледі.

## GitHub Pages-ке жариялау

1. ZIP архивті **ашыңыз**. Архив ішінен `index.html`, `.nojekyll`, `README.md`, `Қайнау_10_сұрақ_үлгісі.csv` файлдарын шығарыңыз.
2. [github.com/new](https://github.com/new) арқылы **Public** репозиторий ашыңыз (мысалы, `bilim-quest`).
3. `Add file → Upload files` арқылы файлдарды **репозиторий түбіріне** жүктеңіз. **ZIP-тің өзін ғана салмаңыз.**
4. `Commit changes` басыңыз.
5. `Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save` таңдаңыз.
6. GitHub біраз уақыттан кейін жария сілтемені **Settings → Pages** ішінде көрсетеді. Жария сілтеме үлгісі: `https://ПАЙДАЛАНУШЫ.github.io/bilim-quest/`.

## Мұғалімге арналған нұсқаулық

1. Басты беттен **«Ойын құру» / «Мұғалім кабинеті»** бөлімін ашыңыз.
2. Пәнді таңдаңыз. Қазір физикада 10 дайын «Дұрыс / Бұрыс» тапсырмасы бар.
3. **«Оқу материалдары»** бөлімінде PDF, Word, PowerPoint, TXT, CSV және суреттерді қоса аласыз. Файлдардың көлемі 25 МБ-тан аспауы керек. Олар **осы браузердегі IndexedDB** қоймасында сақталады. PDF/Word файлын жүктеу оның мазмұнын автоматты түрде сұраққа айналдырмайды.
4. **«Тапсырма құрастырушы»** бөлімінде ашық жауап, қысқа жауап, бір дұрыс жауап, Дұрыс/Бұрыс, сәйкестендіру түрлерін қолданыңыз. Сұраққа JPG/PNG/WebP/GIF суретін (8 МБ-қа дейін) бекітуге болады.
5. **«CSV үлгісін жүктеу»** арқылы CSV пішімін алыңыз. Дәл сол құрылымда құрастырылған сұрақтарды **«Сұрақтарды CSV-дан қосу»** арқылы жүктеңіз. Бұл операция **бұрынғы сұрақтарды жоймай, жаңаларын қосады**.
6. Сұрақтар мәтінін, деңгейін, балын, критерийін өзгертіңіз. **«10 сұрақ үлгісі»** батырмасы тек жоқ үлгі сұрақтарды қосады; бұрын сақталған мұғалім сұрақтарын алмастырмайды.
7. «Мұрағатқа» деген батырма сұрақты уақытша жасырады, толық жоймайды. «Мұрағаттағы сұрақтар» бөлімінде қалпына келтіріңіз.
8. **«Сақтық көшірме»** батырмасы барлық тапсырмалар, жауаптар, рефлексия және жүктелген материалдарды бір **JSON** файлына экспорттайды. Оны қауіпсіз сақтаңыз. **«JSON»** батырмасы басқа браузерге көшіргенде мәліметтерді **қосып қалпына келтіреді**, барын алмастырмайды.
9. Ойын нәтижесін «Құрмет тақтасы» бөлімінен көріңіз; CSV және Excel арқылы экспорттаңыз.

## Есте сақтау және қауіпсіздік

- GitHub Pages **тек сайтты жариялайды**. Бұл нұсқада әр құрылғының тапсырмалары, суреттері және нәтижелері **сол браузерде ғана сақталады** (`localStorage` + `IndexedDB`). Олар **автоматты түрде мұғалімнің, басқа оқушылардың немесе басқа компьютердің экранына тарамайды**.
- GitHub-та `index.html` жаңартылса, сол бір сайт адресінде және сол браузерде сақталған ескі сұрақтарды сақтау кілті өзгермейді (`bilimQuestKZ_v2`); бірақ шолғыш деректерін тазалау, басқа профиль немесе басқа домен қолдану деректерге әсер етуі мүмкін. **JSON сақтық көшірмесін үнемі жасаңыз.**
- **Ортақ тапсырмалар базасы**, қатысушылардың нақты уақытта қосылуы, QR арқылы бір бөлмеге кіру, нәтижелердің бәріне бірдей көрінуі үшін **сервер немесе Firebase / Supabase сияқты дерекқор** керек. Бұл архивте ондай сервер жоқ.
- Нақты оқушылардың жеке деректерін, бағалары мен рефлексиясын жария репозиторийге салмаңыз. Бұл статикалық нұсқада дұрыс жауап кілттері браузердегі код арқылы қолжетімді, сондықтан оны маңызды емтихандарды қорғау үшін қолданбаңыз.

# Инструкция на русском

**BILIM QUEST** — одностраничный HTML-сайт, подготовленный для GitHub Pages. Откройте ZIP, загрузите **`index.html`** в корень публичного репозитория GitHub, затем включите **Settings → Pages → Deploy from a branch → main / (root)**.

Сразу доступен шаблон по физике: **«Қайнау температурасының атмосфералық қысымға байланыстылығын анықтау»**, 10 вопросов «Дұрыс/Бұрыс» с правильными ответами.

**Учительский кабинет:** ручное создание и редактирование пяти видов вопросов, иллюстрации JPG/PNG/WebP/GIF к вопросам, локальная библиотека материалов PDF/DOC/DOCX/PPT/PPTX/TXT/CSV/изображения, массовый импорт вопросов из CSV, экспорт JSON-резервной копии и восстановление без удаления прежних вопросов. Кнопка шаблона теперь **не сбрасывает вопросы**, а перемещение в архив можно отменить.

**Как сохранить свои задания:** после редактирования нажмите «Сақтық көшірме» и храните скачанный JSON отдельно. При смене браузера используйте кнопку импорта JSON. Результаты игры экспортируются в CSV/Excel. Файлы материалов сохраняются в IndexedDB браузера, а текст вопросов — в localStorage.

**Очень важно:** сайт, опубликованный на GitHub Pages, доступен всем по ссылке, но **общего хранилища для разных посетителей здесь нет**. Данные одного учителя не синхронизируются автоматически с другими телефонами или компьютерами. Для этого необходимо подключить облачную базу и авторизацию. Публикация статического HTML на GitHub сама по себе не обеспечивает общий банк вопросов или совместное соревнование в реальном времени.
